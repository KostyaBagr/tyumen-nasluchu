# Тюмень на слуху

Учебный многостраничный городской блог о Тюмени.  
Чистый HTML и CSS, небольшой JS только для бургер-меню.

## Как открыть

Откройте файл `index.html` в браузере (двойной клик или «Open with Live Server»).

## Страницы

| Файл | Содержание |
|------|------------|
| `index.html` | Главная |
| `places.html` | Достопримечательности |
| `food.html` | Еда, видео YouTube, аудио |
| `routes.html` | Пеший маршрут и Яндекс.Карта |
| `about.html` | О блоге и форма обратной связи |

## Структура

- `css/style.css` - единые стили
- `js/menu.js` - мобильное меню
- `images/` - изображения
- `audio/` - саундтрек прогулки
- `docs/defense.md` - текст для защиты и ответы на вопросы

## GitHub Pages (по желанию)

1. Создайте репозиторий и загрузите файлы проекта в корень.
2. GitHub → **Settings** → **Pages**.
3. Source: branch `main`, folder `/ (root)`.
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Пути в проекте относительные - менять ссылки не нужно.
